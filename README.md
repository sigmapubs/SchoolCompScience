# School Computer Science, Explained

Upload files for the SigmaEdu channel "School Computer Science, Explained": original ~10-minute lessons that follow full syllabi course by course and unit by unit (Intro to CS, AP CS Principles, AP CS A, intro college CS in Python).

Each video folder holds `video.mp4` (1080p60 with a caption track), `captions.srt`, `thumbnail.png`, `metadata.json` and `description.txt`.
